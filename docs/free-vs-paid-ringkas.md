# Nawasena: Free vs Paid

Paid = **Paket Mulai Karir**, Rp49.000 sekali bayar.

| Konten | Free | Paid |
|---|:---:|:---:|
| Daftar akun | ✅ | ✅ |
| Unggah CV / Susun CV di aplikasi | ✅ | ✅ |
| Kuis 36 pertanyaan | ✅ | ✅ |
| Saran target karir | ✅ | ✅ |
| **Bagian 1: Kenalan Sama Dirimu**: julukan, yang paling "kamu banget", yang perlu dilatih, tokoh yang mirip (khusus jenjang *entry*) | ✅ | ✅ |
| **Bagian 2: Tipe Karirmu**: spesialis, generalis, atau pemimpin, dan ke mana kamu bergerak | 🔒 | ✅ |
| **Bagian 3: Keunggulan dan Tantanganmu**: cara menceritakan diri + 3 pertanyaan wawancara | 🔒 | ✅ |
| **Bagian 4: Catatan buat CV-mu**: contoh kalimat sebelum dan sesudah, perbaikan cepat | 🔒 | ✅ |
| **Bagian 5: Enam Arah Karir**: kenapa cocok, hari-harinya, jalur karir, kisaran gaji, industri, tempat kerja yang pas | 🔒 | ✅ |
| **Bagian 6: Langkah Sekarang**: 3 hal yang bisa dikerjakan minggu ini | 🔒 | ✅ |
| Unduh PDF *Peta potensimu* | 🔒 | ✅ |
| Unduh PDF CV rapi (kalau CV disusun di aplikasi) | 🔒 | ✅ |
